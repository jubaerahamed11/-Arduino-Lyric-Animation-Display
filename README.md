# -Arduino-Lyric-Animation-Display
An Arduino-based OLED display project that shows song lyrics on screen in sync with the music using programmed timing. The project combines simple Arduino programming with an OLED display to create a small, interactive lyric visualization system.

# 🎵 Arduino Lyric & Animation Display

An Arduino-based OLED project that displays song lyrics along with custom animations, synchronized with the music using programmed timing.

## 🎶 Songs

### 💙 Love Me Not

An OLED lyric and animation display programmed for the song **Love Me Not**.

📁 Project files:
- `LoveMe_Not.ino` — Main Arduino program
- `video_data.h` — Animation/video data

### 🌹 Ekanto Golap

An OLED lyric and animation display programmed for the song **Ekanto Golap**.

📁 Project files:
- `Ekanto_Golap.ino` — Main Arduino program
- `video_data.h` — Animation/video data

## 🔧 Components

- Arduino
- OLED Display
- Breadboard
- Jumper wires

## ✨ Features

- 🎵 Synchronized lyrics
- 📝 Lyrics displayed on OLED
- 🎞️ Custom animations
- ⏱️ Timing-based synchronization
- 💻 Arduino-based programming
